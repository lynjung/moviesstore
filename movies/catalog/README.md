# Approved catalog additions

Run `python manage.py add_favorites` after migrations to add the four selected
movies and copy their bundled posters into the configured media storage. Existing
movies are preserved, and running the command again does not duplicate entries
or overwrite prices, descriptions, or posters already edited through admin.

Prices: La La Land $11; 20th Century Girl $11; Baby Driver $12; Interstellar $14.
Descriptions are original, short summaries.

Poster sources (artwork belongs to the respective rights holders):

- La La Land: https://en.wikipedia.org/wiki/File:La_La_Land_(film).png
- 20th Century Girl: https://en.wikipedia.org/wiki/File:20th_Century_Girl.jpg
